# ClaudeRU

Личный веб-чат, который передаёт сообщения браузеру с claude.ai на домашнем Mac. API-ключ Anthropic не нужен. Это неофициальная автоматизация сайта: интерфейс Claude может измениться, лимиты подписки и проверки входа сохраняются. Проверки сайта не обходятся.

## Что работает в первой версии

- Вход по отдельному паролю сайта, сессии на 12 часов, ограничение попыток входа.
- Новые разговоры, продолжение чата по его адресу, постепенное обновление текста ответа.
- История обёртки в localStorage текущего браузера. На другом устройстве этот список не появится автоматически. Полная история остаётся в claude.ai; импорт существующих чатов пока не реализован.
- Ответы показываются обычным текстом; вложения, Markdown-оформление, инструменты, выбор модели и синхронизация истории между устройствами пока не реализованы. Модель и доступные функции определяются сайтом Claude.

## Установка на домашнем Mac

Нужны Node.js 22 или новее, Git и графический сеанс macOS. Если используете Homebrew: `brew install node`.

```bash
git clone https://github.com/2002stunna/ClaudeRU.git
cd ClaudeRU
npm ci
npx playwright install chromium
npm run setup
npm run login
```

Эти команды предполагают, что код этой версии уже сохранён в вашем репозитории; иначе скопируйте подготовленную папку проекта на Mac и начните с `cd` в неё.

`setup` попросит придумать **отдельный пароль для обёртки** от 12 символов. Ввод виден в терминале. В файле хранится только хеш пароля. Не вводите здесь пароль Claude.

`login` откроет отдельный Chromium. Войдите в claude.ai обычным способом, вручную пройдите необходимые проверки. После входа закройте окно браузера. Не запускайте `login` и сервер одновременно: они используют один профиль.

Для проверки дома:

```bash
npm start
```

Откройте адрес `http://127.0.0.1:3000` на Mac, войдите с паролем обёртки и отправьте короткое сообщение. Должен появиться ответ из Claude. Сервер открывает Chromium с сохранённой сессией; не закрывайте его и не используйте управляемую вкладку во время ответа.

## Яндекс Браузер на Mac

Вместо комплектного Chromium можно попробовать установленный Яндекс Браузер. Установите его из официального источника в `/Applications/Yandex.app`. Закройте браузер, ранее открытый нашей программой, и остановите сервер перед переключением.

```bash
npm run browser:yandex
npm run login
```

Выбор сохраняется локально: следующие `npm start` тоже запустят Яндекс Браузер. Используется отдельный профиль `.local/browser-yandex/`, без доступа к вашему обычному профилю Яндекса. Войдите вручную в открывшемся окне и затем закройте его. Для запуска сайта выполните `npm start` (или `COOKIE_SECURE=1 npm start` при использовании HTTPS-туннеля).

Совместимость Яндекс Браузера с Playwright не гарантирована. Этот выбор не скрывает автоматизацию и не обходит проверки Google или Claude. Если проверка входа повторяется, реальное подключение остаётся заблокированным. Для возврата к Chromium: `npm run browser:chromium`. Папка `.local/browser-yandex/` содержит чувствительные данные сессии; не передавайте её другим. Удалять её для сброса входа можно только при остановленном сервере и закрытом окне автоматизации.

## Доступ из библиотеки или университета

Остановите сервер сочетанием Ctrl+C. Установите Cloudflare Tunnel и запустите сервер с защищённой cookie:

```bash
brew install cloudflared
COOKIE_SECURE=1 npm start
```

Во втором терминале запустите:

```bash
cloudflared tunnel --url http://127.0.0.1:3000
```

Cloudflared напечатает HTTPS-адрес вида `https://случайное-имя.trycloudflare.com`. Откройте **этот HTTPS-адрес** с другого устройства и введите пароль обёртки. При `COOKIE_SECURE=1` вход по локальному HTTP не сохраняется — используйте HTTPS-адрес туннеля.

Это временный адрес: после перезапуска туннеля он меняется. Для постоянного адреса настройте именованный Cloudflare Tunnel с собственным доменом. Cloudflare обслуживает HTTPS-туннель, поэтому участвует в передаче ваших запросов. Не открывайте порт 3000 на роутере: приложение специально слушает только 127.0.0.1. Не публикуйте сайт без пароля.

В третьем терминале можно держать Mac бодрствующим:

```bash
caffeinate -i
```

Оставьте Mac подключённым к питанию и интернету, с открытой крышкой. Команда не гарантирует работу при закрытой крышке. После перезагрузки Mac запустите сервер, туннель и caffeinate снова. При завершении подписки или исчерпании лимитов обёртка не сможет получить ответ.

## Данные и диагностика

- `.local/browser/` содержит сессию Claude: это чувствительные данные. Не передавайте папку другим и не добавляйте её в Git.
- `.local/auth.json` содержит хеш пароля обёртки. Для смены пароля остановите сервер, удалите только этот файл и повторите `npm run setup`. Перезапуск сервера завершает все сессии обёртки.
- Для удаления входа Claude остановите сервер и удалите `.local/browser/`, затем повторите `npm run login`.
- На общем компьютере выйдите из обёртки и очистите данные сайта либо используйте приватное окно: выход завершает сессию, но не удаляет локальную историю чатов.
- Если ответа нет, проверьте управляемое окно на Mac: вход, лимиты, сообщения сайта. Не повторяйте отправку вслепую — сообщение могло уже попасть в Claude.
- Если Claude изменит разметку, потребуются изменения селекторов в `bridge.mjs`. Таймаут ответа — 3 минуты; одновременно выполняется один запрос. Закрытие вкладки обёртки не отменяет уже отправленный запрос.
- Внешний адрес не означает, что Mac доступен: для работы нужны запущенный сервер и туннель.

## Проверки разработки

```bash
npm test
```

Интеграционные тесты запускают настоящий локальный HTTP-сервер, проверяют авторизацию, cookie, защиту от посторонних источников, блокировку параллельных запросов и потоковый протокол с тестовым адаптером Claude. Они не обращаются к аккаунту Claude и не доказывают совместимость с текущей разметкой claude.ai. Реальный вход и ответ требуют проверки на Mac с вашей подпиской.

При разработке используйте существующую рабочую копию; отдельный Git worktree не нужен.
