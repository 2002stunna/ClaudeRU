# ClaudeRU

Личный сайт для общения с Claude через открытую вкладку claude.ai в обычном Яндекс Браузере на домашнем Mac. API-ключ не требуется. Вход выполняется вами в браузере; расширение передаёт сообщения и файлы через локальный сервер. Неофициальная интеграция с интерфейсом сайта: лимиты аккаунта и проверки Claude сохраняются, разметка может измениться.

## Обновление до 0.7.0

1. Остановите сервер в Терминале сочетанием Ctrl+C. Из папки ClaudeRU выполните:

```bash
git pull origin main
npm ci
npm start
```

2. Откройте в Яндексе `browser://extensions/`, включите «Режим разработчика» и нажмите **обновление/перезагрузку на карточке ClaudeRU**. Убедитесь, что версия стала **0.7.0**. Начиная с 0.6.0 требуется разрешение **«Управление загрузками»**; разрешите его, если браузер запросит подтверждение.
В версии 0.7.0 добавлено разрешение `webRequest` для получения результата обычного удаления в Claude; подтвердите обновление разрешений, если браузер запросит его. Содержимое запросов, ответов и cookie не читается.
3. Обновите вкладку claude.ai. Нажмите значок расширения ClaudeRU, вставьте новый код из Терминала и подключите эту вкладку. Не передавайте код другим.
4. Обновите страницу своего сайта. После подключения Mac модели и чаты загрузятся автоматически. Для повторного обновления нажмите **↻ рядом с «Недавние»** или «Обновить из Claude» в меню модели.

В версии 0.4.1 добавлена проверка совместимости сервера, расширения и кода вкладки до выдачи задания. `git pull` обновляет файлы, но не перезагружает расширение или открытую страницу. Если расширение старое, сервер не передаёт ему команды синхронизации и показывает требование обновления. Если устарел только код вкладки, предлагается обновить claude.ai. Окно расширения показывает его фактически загруженную версию рядом с заголовком.

При подключении проверяется доступность кода вкладки и локального сервера. Если сервер отклонил сообщение до передачи в Claude, текст и вложения остаются в черновике сайта. Ошибки после начала выполнения по-прежнему требуют проверки вкладки на Mac перед повтором: автоматически сообщения не пересылаются.

Новый код подключения создаётся при каждом запуске сервера. При старой версии content script сервер попросит обновить расширение и вкладку. Если получить меню моделей не удалось, показывается конкретная ошибка и действие повтора; пустой список не подменяется вымышленной моделью.

## Удаление и обновление списка чатов в 0.7.0

Исправлено серое меню действий: если его открыли во время загрузки или синхронизации, доступность пунктов теперь обновляется после завершения операции. Ожидание ответа в одном чате не блокирует меню другого свободного чата. Удаление по-прежнему требует вашего подтверждения в обёртке, после чего выполняется в настоящем Claude.

Расширение отслеживает **результат обычного запроса удаления** в подключённом браузере, а не просто исчезновение строки из боковой панели. После успешного удаления оно передаёт идентификатор чата локальному серверу, и обёртка автоматически обновляет список по изменению версии истории. Для этого добавлено разрешение `webRequest`; расширение не отправляет запросы к API Claude самостоятельно и не читает тела запросов, ответов или cookie. Неуспешные удаления и ошибки авторизации не убирают чат. При удалении через обёртку также проверяется подтверждённый результат запроса.

Если домашний сервер был выключен, наблюдения сохраняются в расширении и передаются после подключения. На сервере сохраняется отметка удаления, поэтому старый список из другой вкладки не возвращает чат после синхронизации или перезапуска.

Старые строки, удалённые ещё до установки этой версии, проверяются при открытии: подтверждённая недоступность разговора убирает такую строку. Отсутствие в частичном списке «Недавние» само по себе не считается удалением. Для чата, отсутствующего в боковой панели, поддержано меню актуального заголовка `session-title-split`.

Проверки покрывают серое меню во время загрузки, удаление выбранного чата напрямую в Claude, обновление обёртки без ручной синхронизации, очередь при отключённом сервере, защиту от старого списка и сохранение разговоров, которых нет в частичной боковой панели. Это контролируемые проверки; установленное расширение в аккаунте пользователя отсюда не проверено.

## Кнопка отправки в новом чате: 0.6.1

При открытии нового чата Claude переключает голосовой режим и отправку: кнопка отправки может уже находиться в DOM, оставаясь скрытой внутри `inert`. Кроме того, редактируемое поле иногда появляется до подключения его обработчиков ввода. Раньше расширение исключало такую кнопку из поиска, видело уже вставленный текст и больше не уведомляло редактор о вводе. Результатом становилась ошибка «Не найдена кнопка отправки».

Теперь скрытая или неактивная кнопка распознаётся как ещё не готовая. Если её состояние не обновилось, расширение до двух раз повторно вводит **тот же текст** через штатное редактирование поля; ручные изменения прекращают восстановление. Кнопка может находиться в соседней панели с полем, а её название может задаваться через `aria-labelledby`. Контролы другой формы, другого редактора и меню не используются.

После замены редактора или кнопки заново проверяются 400 мс стабильной готовности. Отправка по-прежнему выполняется одним нажатием с проверкой появления сообщения. В отчёт «Диагностика файлов» добавлены состояние загрузки страницы и признаки видимости, `inert` и доступности кнопок отправки. Для этой версии обязательно обновление расширения **и** вкладки Claude.

## Скачивание файлов браузером в 0.6.0

Для файлов с собственной кнопкой скачивания расширение нажимает **«Скачать» на карточке Claude**, дожидается состояния завершённой загрузки в браузере и передаёт домашнему серверу сведения об этом файле. Сервер читает скачанные байты и сохраняет отдельную копию в `.local/files`. Из обёртки скачивается именно эта копия; адреса Claude не передаются пользователю как ссылки для скачивания.

По присланной диагностике учтена реальная карточка `file-card-block` с кнопкой «Скачать Burger». Предварительно открывать просмотр не требуется: он находится в iframe `claudeusercontent.com`, адрес которого не является адресом PDF. Перехват кликов в основном мире страницы из 0.5.6 удалён. Работают штатные события Downloads API, поэтому этой версии нужно разрешение браузера **`downloads`**.

Файлы этих операций браузер сохраняет в подпапку **`ClaudeRU/<идентификатор операции>/`** своего каталога загрузок. Завершённый файл остаётся там, а обёртка хранит независимую копию. Обычная синхронизация повторно использует уже сохранённый файл в текущей вкладке; **↻ в заголовке** явно скачивает его заново. Для старого ответа с PDF после обновления нажмите эту кнопку.

В обёртку принимаются только завершённые файлы из каталога текущей операции. Сохраняются ограничения: до 5 файлов, до 20 МБ каждый и до 25 МБ суммарно. Если браузер показывает выбор места сохранения, подтвердите предложенную папку ClaudeRU: по ней сервер находит файл. Для автоматической работы отключите в настройках загрузок браузера запрос места сохранения каждого файла.

Проверка выполняет настоящее скачивание PDF в Chromium, проводит его через рабочий код контроллера и фонового процесса и проверяет ответ локального сервера после удаления исходного файла. События Downloads API в этой проверке адаптируются из событий Playwright: политика браузера рабочей среды запрещает установку unpacked-расширений. Отдельно проверены привязка загрузки к чату, завершение загрузки, защита от повторного импорта, неверного каталога и подмены PDF страницей просмотра. Реальный аккаунт пользователя отсюда не проверен.

## Передача изображений и PDF в 0.5.6

Исправлена пропущенная обработка изображений: расширение читает фактический `src`/`currentSrc` из ответа Claude, включая адреса вида `/api/…/files/…/preview`, `blob:` и растровые `data:`. Учитываются изображения рядом с текстом внутри того же ответа; аватары и изображения из других сообщений исключаются. Перед сохранением проверяются байты изображения. В обёртке отображаются миниатюра и явная кнопка **«Скачать»**. Просмотр растрового изображения идёт через авторизованный локальный сервер; HTML и SVG не открываются в этом режиме. Внешние HTTPS-изображения запрашиваются только по адресу, уже представленному в ответе, через CORS, без отправки cookie.

Добавлен перенос PDF, когда карточка открывает просмотр, а кнопка «Скачать» создаёт временный blob без ссылки в HTML. Небольшой скрипт в основном мире страницы получает только PDF, выданный этой кнопкой во время явного запроса обёртки. Он не перехватывает сетевые запросы, не обращается к неизвестным API и не читает учётные данные. Обычные скачивания вне этого запроса работают как раньше. Дополнительных разрешений расширения нет. Если доступного PDF или подходящей кнопки нет, файл не подменяется текстом или страницей просмотра.

Поле сообщения со стабильным `chat-input` теперь имеет приоритет перед редакторами артефактов. При входе ввод становится доступен после загрузки выбранного чата, чтобы стартовая синхронизация не сбрасывала быстро набранный текст. Неотправленный текст, вставленный самой обёрткой, можно заменить новым запросом после ошибки; ручные изменения и вложения защищены от перезаписи. Черновик при подтверждённой ошибке до отправки сохраняется на Mac и восстанавливается после обновления обёртки.

Для ранее созданного файла откройте соответствующий чат в обёртке и нажмите **↻ в заголовке**. Если карточки всё ещё нет, пункт **«Личное пространство → Скачать диагностику файлов»** сохраняет JSON со структурой карточек, адресами без значений параметров и размерами изображений. В отчёт не включаются текст переписки, содержимое файлов и cookie. Он помогает проверить фактическую разметку вашего Claude без ручного поиска HTML.

Проверки Chromium покрывают PNG по адресу такого же формата, data/blob, изображения рядом с текстом, скачивание через сервер на мобильном экране и PDF через кнопку без DOM-ссылки, включая разделение основного и изолированного миров расширения. Это контролируемые сценарии; скачивание в конкретном аккаунте пользователя отсюда не проверено.

## Проверка готовности отправки в 0.5.5

Обычный текст больше не проходит проверку загрузки файлов: посторонний индикатор загрузки или `aria-busy` в поле сообщения не блокирует отправку без вложений. Для запросов с файлами проверка их обработки сохраняется.

Кнопка ищется в активном поле текущего редактора. Учитываются её `aria-label`, название и известные метки; значок стрелки не скрывает доступное название. Неактивные копии редактора и кнопки вне поля не используются. Проверяется также запрет отправки на родительском `fieldset`.

Если после неудачной попытки в Claude остался точно такой же текст, запрос без вложений можно отправить повторным нажатием в обёртке. Текст не вставляется второй раз. Другой черновик или уже прикреплённые во вкладке файлы сохраняются и не отправляются этим повтором. При тайм-ауте сообщение указывает конкретную причину: не найдено поле/кнопка, кнопка запрещает отправку, обрабатывается вложение или меняется редактор. Автоматических повторных нажатий после отправки нет.

## Исправления распознавания и удаления в 0.5.4

Распознавание PDF теперь учитывает карточки, где кнопка с названием и строка «Документ · PDF» находятся в соседних элементах без известных `data-testid`. Такая карточка рассматривается целиком; её служебный текст не добавляется к ответу. Добавлены проверки именно этой структуры.

Действия с чатами не создают дополнительные вкладки. Используется уже открытая свободная вкладка Claude; когда все вкладки заняты, показывается понятная ошибка. Если выбранная рабочая вкладка закрыта, для удаления она не создаётся заново.

Меню ищется только в строке заданного чата или в его заголовке. Поиск не переходит на соседние разговоры. Для удаления и архивирования расширение ждёт появления подтверждения и результата, вместо однократной проверки через 100 мс. До подтверждённого результата чат не исчезает из списка обёртки.

Браузерные проверки подтверждают перечисленные сценарии на контролируемой разметке. Для проверки совпадения с конкретным обновлённым интерфейсом Claude необходима его текущая HTML-разметка: одни скриншоты не содержат адресов файлов и атрибутов элементов.

## Быстрая отправка вложений в фоновой вкладке в 0.5.3

Когда Claude открыт в фоне, браузер может растягивать таймеры страницы на секунды. Из-за этого уже прикреплённый и готовый файл оставался в поле сообщения до следующей проверки. Короткие ожидания теперь выполняет фоновая часть расширения: они не зависят от таймеров скрытой страницы и не создают запросов к локальному серверу. Разрешены только паузы до одной секунды для текущего задания и его вкладки.

Проверка обработки вложения, доступности кнопки и сохранности текста остаётся. Готовое поле проверяется каждые 100 мс; после 400 мс стабильного состояния выполняется одно нажатие. Дополнительного десятисекундного ожидания готового файла нет. Обработка файла самим Claude всё ещё должна завершиться перед отправкой. Проверки Chromium воспроизводят задержку таймеров страницы в 10 секунд для изображения и PDF: уже готовые вложения отправляются меньше чем через секунду.

После обновления перезагрузите расширение **и** вкладку Claude, затем подключите заново. Сохранённый кэш уровней усилий не сбрасывается.

PDF, которые Claude выдаёт карточкой «Документ·PDF», теперь переносятся через просмотр документа. Расширение получает предоставленный интерфейсом адрес PDF или blob, проверяет содержимое и сохраняет настоящий файл с исходным именем. В обёртке появляется карточка **«Скачать»**. Текст карточки Claude больше не добавляется в тело ответа. Старый PDF из уже открытого просмотра и HTML-страница вместо PDF не сохраняются как новый документ. Для переноса PDF из ранее открытого разговора обновите этот чат.

## Сохранённые уровни усилий и интерфейс в 0.5.2

В меню остаются только **Fable 5.1, Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5 и Opus 5**, в этом порядке. При первом подключении расширение один раз считывает доступные уровни отдельно для каждой из этих моделей, затем восстанавливает исходные модель и усилие. Недоступные в аккаунте модели отмечаются недоступными; отсутствие уровней также сохраняется как результат.

Результат хранится на Mac в **`.local/model-catalog.json`** и используется всеми чатами и устройствами после переходов между страницами, перезагрузки расширения и перезапуска сервера. Автоматического сброса или срока действия кэша нет. Открытие чата, выбор модели и обычная синхронизация больше не обходят списки уровней. Для повторного чтения по вашему запросу есть пункт **«Заново считать уровни усилий»** в меню модели.

Проверка реально выбранных модели, усилия и лимита сохраняется. При применении настройки расширение по-прежнему нажимает соответствующий пункт в настоящем Claude и проверяет результат; это не повторное обнаружение списка уровней. Во время первого прохода по моделям сообщения не отправляются. Если в выбранной вкладке идёт ответ, чтение откладывается до свободной вкладки. Новая команда инициализации требует актуального кода расширения и вкладки: обновите оба после установки версии.

Над полем ввода больше нет служебных плашек «Claude отвечает», «Файлы готовы к отправке», переключения модели и синхронизации. Здесь остаются ошибки и предупреждения. На большом экране ширина поля и колонки переписки увеличена до 1200 CSS-пикселей, поле ввода стало выше; мобильная версия сохраняет ширину экрана.

## Исправления 0.5.1

Устранена ошибка `Invalid URL`, возникавшая при открытии новой вкладки: браузер может сначала вернуть пустой адрес или `about:blank`. Расширение дожидается загрузки нужной страницы Claude и только затем выполняет действие. Открытие и удаление другого чата теперь используют свободную вкладку; дополнительная создаётся лишь тогда, когда все имеющиеся заняты.

Обычное переключение чатов больше не открывает панели артефактов и не показывает предупреждение о невозможности их экспорта. Попытка получить файл выполняется после нового ответа либо по кнопке ↻ в заголовке чата. При этом расширение ждёт загрузки панели и вкладки «Код», не берёт код из ранее открытого артефакта и проверяет ссылки внутри новой панели. Если получить файл не удалось, появляется сообщение «Не удалось добавить файл артефакта в этот чат. Его можно открыть и скачать на claude.ai». Ответ Claude остаётся доступен.

## Модель, лимиты и независимые чаты в 0.5.0

Модель и усилие проверяются в Claude при каждом открытии разговора, включая новый чат. Затем их состояние и сообщение об исчерпанном лимите обновляются раз в секунду, пока чат свободен. Настройки предыдущего разговора не используются как фактические настройки нового. Предупреждение Claude о кредитах или лимите отображается над полем сообщения и блокирует отправку; выбор другой модели остаётся доступен. Если отказ появился после нажатия отправки, ожидание завершается с этой ошибкой, без автоматического повтора.

Выбор усилия теперь сразу изменяет его в настоящем Claude. Подтверждённый выбор отображается после проверки вкладки. В версии 0.5.2 уровни усилий считываются один раз и сохраняются; при открытии чата и переключении модели используется кэш. Постоянная пауза перед сменой настройки отсутствует; загрузка страницы и скорость сети могут добавлять задержку.

Запросы, потоки ответов и блокировки разделены по чатам. Пока один разговор отвечает, можно создать другой, выбрать модель и написать ему. Расширение использует до **6 вкладок Claude**, повторно используя свободные и создавая дополнительные в фоне только при одновременной работе нескольких чатов. Оно не закрывает посторонние вкладки. Эти вкладки нужно оставить открытыми; не ведите в них параллельную ручную переписку. Все они используют обычную сессию вашего браузера и общие лимиты аккаунта.

У каждой строки разговора появилось меню **…**: отметить непрочитанным, закрепить/открепить, переименовать, переместить в существующую группу, архивировать и удалить. Для разговоров с адресом Claude действия выполняются через его интерфейс; изменение в обёртке сохраняется после подтверждения вкладкой. При недоступном пункте показывается ошибка. Удаление требует подтверждения и удаляет чат также на claude.ai. Архивированные разговоры доступны через «Архив», удалённые не появляются заново после синхронизации. Новый разговор без адреса Claude пока существует только в обёртке, поэтому его организация локальная. Группы берутся из доступного меню Claude; создание групп в обёртке не добавлено.

## Исправление отправки вложений в 0.4.3

У изображений в Claude может быть только миниатюра, без видимого имени файла. В версии 0.4.3 ожидание учитывает такую миниатюру, а не только подпись. Проверка ограничена полем составления сообщения, чтобы старые вложения в истории не считались новой загрузкой. Расширение ждёт окончания обработки файла и доступности отправки; при обновлении редактора заново находит его и восстанавливает только свой текст в пустом поле.

После единственного нажатия кнопки проверяется появление нового сообщения или начала ответа. Если подтвердить отправку не удалось, повторного автоматического нажатия нет. Если ошибка произошла до нажатия, текст и файлы восстанавливаются в черновике нашего сайта, а не остаются ложным отправленным сообщением в истории.

Если после предыдущей ошибки в Claude уже остался файл, сначала отправьте этот черновик вручную либо сохраните нужный текст и уберите вложение. Новый запрос не добавляет тот же файл поверх оставшегося. Для этой версии обязательна перезагрузка расширения **и** вкладки Claude: старый протокол больше не получает задания.

## Частота обновления и скорость

В версии 0.4.2 сайт проверяет соединение раз в **1 секунду**. Локальный сервер возвращает пустой запрос расширения через 1 секунду, а при появлении задания пробуждает уже ожидающий запрос сразу. Прежняя пауза до 15 секунд перед выдачей задания устранена. Повторные запросы состояния не накладываются друг на друга.

Открытая страница Claude используется повторно. Сервер не перезагружает её ради опроса. Переход выполняется, когда нужен другой разговор; адреса `/` и `/new` распознаются как одна страница создания чата. Готовая вкладка обрабатывает задание без дополнительной паузы 500 мс.

Во время ответа расширение считывает текст каждые **250 мс** и передаёт изменения потоком. Сайт обновляет только активный ответ, сохраняя уже показанные сообщения. При явном признаке завершения от Claude дополнительно ожидается 0,5 секунды стабильного состояния, после чего передаются файлы. Для старой разметки без признака завершения остаётся более осторожное ожидание. Скорость самой генерации Claude и ограничения аккаунта от этого не меняются. Фоновое замедление вкладки браузером и проблемы сети могут увеличивать фактическую задержку.

## Интерфейс по HTML-шаблонам

В версии 0.4.0 переработаны пустая сессия, белая область разговора, светлая боковая панель, поле сообщения и нижняя строка управления. Модель отображается справа под полем; её меню раскрывается в подменю «Другие модели» и «Уровень усилий», с отметками выбранных значений. Кнопка ＋ открывает меню файлов. Обычных HTML-select больше нет.

Боковая панель поддерживает создание, поиск, сортировку, закрепление и переименование разговоров. Меню у заголовка переименовывает и закрепляет чат также в Claude; при обновлении отображается имя из настоящего разговора. Раздел «Артефакты» показывает созданные файлы во всех сохранённых разговорах, кнопка файлов в заголовке — вложения текущего разговора.

HTML-шаблоны использованы как образец структуры и реальных DOM-меток. Их отдельные папки CSS/шрифтов не были приложены; визуальное оформление воссоздано локальными стилями и SVG-иконками. Для подключения к реальному Claude используются `model-selector-dropdown`, `chat-input`, `chat-input-send`, `file-upload`, `user-message` и `assistant-message`. В актуальном шаблоне класса `font-claude-response` нет; он оставлен только как резерв для старой разметки.

## Модели, усилия и чаты

- Нажмите название модели справа под полем сообщения, затем «Другие модели» или «Уровень усилий». Имена моделей получаются из меню вашего Claude; вымышленные или недоступные варианты не добавляются.
- При выборе модели расширение переключает её в Claude и показывает сохранённые для неё уровни усилий. Выбор сохраняется отдельно для каждого чата.
- Перед отправкой расширение проверяет выбранные модель и усилия. Если они недоступны или смена не подтверждается, сообщение не отправляется, сайт показывает ошибку. Если настройка ещё не выбрана, используется текущее значение открытой вкладки; оно отображается после автоматического подключения.
- Максимальный уровень усилий может заметно быстрее расходовать лимиты подписки. Обёртка не расширяет возможности аккаунта.
- Слева — список разговоров с поиском и кнопкой создания чата. На узком экране список открывается кнопкой ☰.
- **↻ рядом с «Недавние»** импортирует ссылки на чаты из загруженной боковой панели Claude. Старые чаты, которых нет в загруженной разметке, не обнаруживаются автоматически. Откройте/прокрутите список в Claude на Mac и повторите синхронизацию.
- При открытии разговора расширение использует его вкладку или переходит в него и считывает отображённые сообщения. Виртуализированная или ещё не загруженная часть истории может отсутствовать. **↻ рядом с названием текущего чата** перечитывает его содержимое и файлы.
- Сохранённые чаты можно просматривать и переключать, пока идёт ответ в другом разговоре. В одном чате одновременно выполняется одна изменяющая операция; другие чаты работают независимо.

## Входящие и созданные файлы

Кнопка **＋** под полем сообщения открывает меню; выберите «Загрузить или добавить файлы». Их также можно перетащить на поле сообщения. До **5 файлов**, каждый до **20 МБ**, всего до **25 МБ** на запрос. Это лимиты обёртки; Claude может отклонить тип файла или ограничить загрузку дополнительно.

Сначала файлы передаются на домашний Mac, затем расширение прикрепляет их к сообщению в настоящем Claude. Карточки вложений можно убрать из черновика до отправки. Неподтверждённая загрузка не считается успешной.

Созданные файлы появляются карточками под ответом с кнопкой скачивания. Текст, код, CSV, JSON, HTML и другие текстовые форматы можно просмотреть в диалоге. HTML/JavaScript показываются как текст и не исполняются в обёртке. Код в ответах дополнительно экспортируется в файлы с подходящим расширением.

Мост переносит доступные в ответе ссылки на скачивание с claude.ai и blob-ссылки этого же сайта, а также исходный код, показанный в открытой панели артефакта. Универсальная поддержка всех вариантов артефактов не гарантирована: кнопки без доступного адреса/исходного кода, внешние домены, перенаправления и интерактивные приложения могут не переноситься. При ошибке передачи появится предупреждение. Если код артефакта скрыт, откройте его вкладку «Код» на Mac и нажмите ↻ рядом с названием чата на нашем сайте.

Скачивание из нашей обёртки требует входа. Файлы отдаются как вложения, без исполнения содержимого на сайте. Готовые PDF/таблицы/документы можно скачать, если Claude предоставил поддерживаемую ссылку. Предпросмотр таких двоичных форматов пока не реализован.

## Где хранится история

Чаты, выбранные настройки и метаданные вложений сохраняются на Mac в **`.local/chats.json`**, содержимое файлов — в **`.local/files/`**. При входе с другого устройства доступна та же сохранённая история. Для обновления списка на уже открытом устройстве перезагрузите сайт или нажмите синхронизацию.

История прежней версии из localStorage переносится в серверное хранилище один раз при входе с того браузера, где она была сохранена. Старые локальные записи остаются резервной копией. Пароль сайта хранится в `.local/auth.json` как хеш. Не передавайте `.local` другим и не добавляйте её в Git. Загруженные/созданные файлы сохраняются на Mac; автоматической очистки хранилища пока нет.

## Первая установка на Mac

Нужны Node.js 22+ и Git:

```bash
git clone https://github.com/2002stunna/ClaudeRU.git
cd ClaudeRU
npm ci
npm run setup
npm start
```

Создайте отдельный пароль сайта от 12 символов. Ввод при `setup` виден в терминале. Не вводите здесь пароль Claude.

### Расширение в обычном Яндексе

1. Откройте `browser://extensions/`, включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите **папку `extension` внутри ClaudeRU**.
2. Откройте claude.ai в этом же браузере, войдите самостоятельно и обновите вкладку.
3. На вкладке Claude нажмите значок расширения ClaudeRU и вставьте код подключения из Терминала сервера. Нажмите «Подключить эту вкладку».
4. Откройте `http://127.0.0.1:3000`, войдите с паролем сайта и дождитесь автоматической загрузки моделей и чатов.

Расширение использует выбранную вкладку и при необходимости создаёт дополнительные вкладки Claude для других чатов. Не используйте эти вкладки для параллельной ручной переписки. Неотправленный текстовый черновик расширение не перезаписывает. Ваша сессия остаётся в обычном Яндексе: Playwright не запускается, пароли и cookies расширение не читает.

Если внутренние страницы браузера пустые, завершите предложенное Яндексом обновление и перезапустите браузер. Если расширение нельзя включить, проверьте режим разработчика. Дополнительная диагностика только для чтения:

```bash
npm run diagnose:yandex
```

Она читает регистрационные поля расширений из `Preferences`/`Secure Preferences` стандартных профилей и при необходимости их `manifest.json`, но выводит только метаданные ClaudeRU. Не выводит пути к расширениям, cookies, историю, пароли или код подключения. Коды объясняются по [перечислению Chromium](https://github.com/chromium/chromium/blob/main/extensions/browser/disable_reason.h); у Яндекса могут быть дополнительные причины. Файлы профиля никому не отправляйте. Стандартная папка — `~/Library/Application Support/Yandex/YandexBrowser`.

## Доступ из другого места

Сначала проверьте локальную работу. Для доступа извне установите Cloudflare Tunnel, например через Homebrew:

```bash
brew install cloudflared
```

Остановите сервер и запустите с защищённой cookie:

```bash
COOKIE_SECURE=1 npm start
```

Вставьте новый код в расширение. Во втором терминале:

```bash
cloudflared tunnel --url http://127.0.0.1:3000
```

Откройте напечатанный HTTPS-адрес с другого устройства и войдите. При `COOKIE_SECURE=1` используйте этот HTTPS-адрес: вход через локальный HTTP не сохраняется. Временный адрес меняется при перезапуске туннеля. Для постоянного адреса нужен именованный туннель и собственный домен. Cloudflare участвует в передаче запросов.

Туннель должен вести только на порт **3000**. Порт **3001** — только локальное соединение с расширением: его не публикуйте. Оба сервера слушают 127.0.0.1. `PORT` меняет порт сайта, локальный мост остаётся на 3001. Порты роутера открывать не требуется.

Mac должен оставаться включённым, с открытой крышкой, питанием и интернетом. Нужны запущенные сервер, туннель, Яндекс и выбранная вкладка Claude. Можно запустить `caffeinate -i` в отдельном терминале, чтобы предотвратить обычный переход в сон. Если Яндекс выгружает вкладку в фоне, исключите её из режима экономии ресурсов через настройки браузера. После перезагрузки снова запустите сервер и туннель, откройте Claude и переподключите расширение.

## Диагностика и разработка

Мост ждёт до 4 минут и не повторяет отправку автоматически. При обрыве проверьте вкладку на Mac перед повторной отправкой: сообщение могло уже попасть в Claude. Закрытие сайта или отключение расширения не отменяет уже отправленный запрос. Статус «Mac подключён» означает связь с расширением, а не успешный вход в Claude или наличие лимита. Сессии сайта действуют 12 часов и сбрасываются при перезапуске сервера.

Для смены пароля остановите сервер, удалите только `.local/auth.json` и повторите `npm run setup`. На общем компьютере пользуйтесь приватным окном и выходите из сайта.

```bash
npm test
```

Тесты проверяют авторизацию, cookie, защиту источника, протокол расширения, сохранение истории и файлов после перезапуска, загрузку/скачивание, немедленное применение настроек, фактическую модель и лимит, независимые чаты и адресацию событий между вкладками, действия с чатами, отказ при недоступной модели/усилиях, сохранение черновика и безопасный просмотр файла. Браузерные проверки запускают настоящий Chromium **на контролируемой HTML-странице**, воспроизводящей меню и файловый ввод; тест сайта использует тестовый мост. Они не входят в реальный Claude и не доказывают совместимость с текущей разметкой вашего аккаунта.

Для браузерных тестов нужен установленный Chromium: `npx playwright install chromium`, либо `CHROMIUM_EXECUTABLE=/путь/к/браузеру npm test`. При отсутствии бинарника браузерные тесты явно пропускаются. Остальные тесты выполняются. После изменения `extension` перезагрузите расширение и вкладку Claude.

Используйте существующую рабочую копию, отдельный Git worktree не нужен. Прежний экспериментальный режим `BRIDGE_MODE=browser npm start` оставлен только для текстовой разработки; новые настройки, загрузка файлов и синхронизация требуют расширения. Старые профили `.local/browser/` и `.local/browser-yandex/` в новом режиме не используются и содержат чувствительную сессию, не передавайте их другим.
