# ClaudeRU

Личный сайт для общения с Claude через открытую вкладку claude.ai на домашнем Mac. API-ключ не требуется. В новой версии сервер по умолчанию работает через расширение в вашем обычном Яндекс Браузере: Playwright не запускается, вход выполняется вами вручную.

Это неофициальное взаимодействие с интерфейсом сайта. Расширение не скрывает свои действия и не обходит проверки Claude или Google. Разметка сайта, лимиты подписки и фоновые ограничения браузера могут мешать работе. Реальный ответ Claude требуется проверить на вашем Mac; серверные тесты не подтверждают совместимость с текущим сайтом.

## Обновление существующей установки

Остановите старый сервер Ctrl+C и закройте окна, которые запускала наша программа. В терминале из папки ClaudeRU:

```bash
git pull origin main
npm ci
npm start
```

Сервер напечатает **код подключения расширения**. Не отправляйте его другим: он разрешает управлять мостом. После перезапуска сервера код меняется; вставьте новый код в расширение. Это отдельный код, не пароль сайта и не пароль Claude.

## Установка расширения в обычный Яндекс

1. Откройте обычный Яндекс Браузер вручную. В адресной строке откройте `browser://extensions` (если недоступно — `chrome://extensions`).
2. Включите «Режим разработчика», нажмите «Загрузить распакованное расширение» и выберите **папку `extension` внутри ClaudeRU**. Если Яндекс не предоставляет установку распакованных расширений в вашей версии, потребуется уточнить поддерживаемый им способ установки; совместимость всех версий не проверена.
3. Откройте `https://claude.ai` в этом же браузере и войдите в аккаунт обычным способом. Обновите страницу после установки расширения.
4. Находясь на вкладке Claude, нажмите значок расширения ClaudeRU (можно найти в меню расширений у адресной строки).
5. Вставьте код подключения из терминала и нажмите **«Подключить эту вкладку»**.
6. Не закрывайте выбранную вкладку. На сайте ClaudeRU появится «Mac подключён» (обновление статуса может занять 15–30 секунд).

На Mac откройте `http://127.0.0.1:3000`, войдите с паролем, созданным ранее через `npm run setup`, и отправьте короткое сообщение. Проверьте, что оно появилось в выбранной вкладке Claude и ответ вернулся на сайт. Если нет — проверьте вкладку Claude, сообщение ошибки на сайте и статус в окне расширения.

Выбранная вкладка управляется расширением: новый разговор открывает `/new`, продолжение — сохранённый адрес чата. Не используйте её для параллельного ручного общения. Неотправленный черновик расширение не перезаписывает. Личные вкладки и ваш обычный профиль не копируются. Чтобы прекратить работу, нажмите «Отключить» в расширении; уже отправленное сообщение это не отменяет.

## Первая установка на Mac

Нужен Node.js 22+ и Git. Если проект ещё не скачан:

```bash
git clone https://github.com/2002stunna/ClaudeRU.git
cd ClaudeRU
npm ci
npm run setup
npm start
```

`setup` попросит создать отдельный пароль сайта от 12 символов. Ввод виден в терминале; сохраняется только хеш. Не вводите пароль Claude. Затем установите расширение по инструкции выше. В новом режиме команды `npm run login`, `npm run browser:yandex` и установка Chromium **не нужны**.

## Доступ из библиотеки или университета

Сначала проверьте обмен сообщениями дома. Для внешнего доступа установите Cloudflare Tunnel, например через Homebrew:

```bash
brew install cloudflared
```

Остановите сервер и запустите его с защищённой cookie:

```bash
COOKIE_SECURE=1 npm start
```

Вставьте новый код подключения в расширение. Во втором терминале:

```bash
cloudflared tunnel --url http://127.0.0.1:3000
```

Cloudflared напечатает HTTPS-адрес. Откройте его на другом устройстве и войдите с паролем сайта. При `COOKIE_SECURE=1` вход по локальному HTTP не сохраняется — используйте HTTPS-адрес туннеля.

Туннель ведёт только на порт **3000**. Порт **3001** служит только расширению на Mac: не публикуйте его и не создавайте для него туннель. Оба сервера слушают 127.0.0.1. Смена `PORT` меняет порт сайта; расширение использует фиксированный порт 3001.

Временный адрес туннеля меняется после перезапуска. Для постоянного адреса нужен именованный Cloudflare Tunnel с собственным доменом. Cloudflare участвует в передаче запросов через HTTPS. Не открывайте порты роутера.

Оставьте Mac включённым, с открытой крышкой, питанием и интернетом. В отдельном терминале можно запустить `caffeinate -i`. Нужны работающие сервер, туннель и обычный Яндекс с выбранной вкладкой Claude. Если браузер выгружает эту вкладку или отключает расширение в фоне, исключите её из режима экономии ресурсов через настройки браузера. После перезапуска Mac снова запустите сервер и туннель, откройте Claude и подключите расширение с новым кодом.

## Данные, возможности и ограничения

- Сайт поддерживает текстовые разговоры и постепенное обновление ответов. Оформление Markdown, вложения, инструменты и выбор модели пока не реализованы.
- Список чатов и текст обёртки хранятся в localStorage каждого устройства; автоматической синхронизации списка между устройствами нет. Claude также хранит чаты в аккаунте; импорт старых чатов пока не реализован.
- На общем компьютере используйте приватное окно. Выход завершает сессию сайта, но не удаляет локальную историю.
- Расширение работает с DOM страницы Claude; не читает пароли и cookie. Код подключения хранится в локальном хранилище расширения, недоступном content script. Не передавайте профиль браузера другим.
- `.local/auth.json` содержит хеш пароля сайта. Для смены пароля остановите сервер, удалите только этот файл и повторите `npm run setup`. Перезапуск сервера завершает сессии сайта.
- Одновременно выполняется один запрос. Мост ждёт до 4 минут; отправка повторно автоматически не выполняется. Если соединение прервалось или произошла ошибка, проверьте вкладку Claude перед повтором: сообщение могло быть отправлено.
- Признак «Mac подключён» означает, что расширение связывается с сервером. Он не доказывает вход в Claude, доступность лимита или успешность ответа.
- Селекторы в `extension/content.js` зависят от разметки Claude. Определение завершения ответа основано на кнопке остановки и стабилизации текста; длинная пауза может выглядеть как завершение.
- Проверки входа, ограничения подписки и проверки сайта выполняются штатно вручную. При повторяющейся проверке подключение остаётся заблокированным.

## Разработка и проверки

```bash
npm test
```

10 тестов проверяют сервер сайта, авторизацию, защиту источника запроса, cookie, одновременные запросы и протокол расширения: код подключения, передачу задания, обновления ответа, ошибки и таймаут. Тесты используют настоящий локальный HTTP-сервер, тестового клиента расширения и модель DOM для проверки отправки и сохранения черновика. Они не запускают Яндекс и не входят в Claude. Проверка расширения с реальной вкладкой остаётся ручной.

Используйте существующую рабочую копию, отдельный Git worktree не нужен. После изменения файлов расширения нажмите «Обновить» на странице расширений и обновите вкладку Claude.

Прежний экспериментальный режим Playwright оставлен для разработки: `BRIDGE_MODE=browser npm start`. Только для него нужны `npx playwright install chromium`, `npm run login` и, при необходимости, `npm run browser:yandex`. Старые сессии в `.local/browser/` и `.local/browser-yandex/` чувствительны и не используются новым режимом; не передавайте их другим.
